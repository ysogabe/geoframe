# 国・地域別の場所表示 PRD

作成日: 2026-11-04。状態: 承認済み（2026-11-04）。設計レビュー 2 回反映済み。実装中。

## 背景と目的

現在のライブラリは、日本の都道府県・市区町村で写真を集計し、`pref` が空の写真を「海外・不明」にまとめる。
この区分には国外だけでなく国内の地名未設定も含まれる。海外の旅を国・州などから探せるようにする。
座標と公開行政境界の照合による分類を使い、写真や撮影座標を外部サービスへ送信しない。

## 使う人と場面

- 管理者が、ライブラリの「場所」で国を選び、その国の第1行政区画（州・県など）へ絞って写真を見る。
- 地図を動かして、その範囲内の国・地域と写真を探す。
- 日本の写真は引き続き都道府県・市区町村から探す（今の地理院による `pref/city` をそのまま使う）。
- 国名・地域名の日本語名または原表記の一部から候補を選ぶ。

## ゴール / やらないこと

ゴール:

- 国・地域（国に準じて独立して扱う地域も含む）→第1行政区画→写真の順に探せる。
- 日本は今の都道府県→市区町村の表示と精度を落とさない。
- 区域内の一致と分類できない状態を混同しない。
- 既存写真も自動で分類され、位置修正・取り込み・推定位置変更の後には再分類される。

今回やらないこと:

- 日本の写真を境界データで分類し直すこと。`pref` が入っている写真は日本・その都道府県とみなす。
- 海岸線から外れた点を近くの国・地域へ割り当てる近隣推定。効果を測ってから別の目的で検討する。
- `infer` で座標が変わったときに `pref/city` が残る既知の制約の修正（別の目的として扱う）。
- 海外の市区町村・施設・住所・標高の取得、画像からの新たな撮影地推定。
- 撮影日時点の歴史的な行政区画の復元。採用データの区画を使う。
- 地域そのものの境界線を地図に描く機能。
- 地域名を写真ごとに手動上書きする機能。
- 公開写真フィードのJSON契約の変更、旅の時間による区切り方の変更。
- 地図の世界周回や日付変更線をまたぐドラッグ範囲の検索。国選択時の安全な表示は設計で定義する。

## 要求

- R1（必須）: 「海外・不明」1枚への集約を、新しい国・地域別カードと未分類カードに置き換える。
- R2（必須）: 国カードを選ぶと第1行政区画を展開し、国全体の写真を表示する。地域選択でその写真へ絞る。
  日本では都道府県→市区町村も選べる。国・地域カードに代表写真と枚数を付ける。
  第1行政区画は Natural Earth Admin1 をそのまま使う（国によって細かさが違う。例: 英国は州・自治体単位）。
- R3（必須）: 期間・地図表示範囲・除外の有無が、件数・代表写真・写真の絞り込みに一貫して反映される。
  地図の点は従来どおり期間・除外で絞った周辺の写真を表示し、場所選択後も他地域の位置関係を残す。
- R4（必須）: 場所検索、旅の地名表示と文字検索、ライブラリ写真詳細で国・地域の情報を使う。
- R5（必須）: 国が分かるが地域が分からない写真は、その国の「地域不明」から選べる。
  国まで分からない座標あり写真は「地域未判定」、座標なし・無効な写真は「場所不明」として別に選べる。
- R6（必須）: 日本は `pref` が空でない写真を（座標の有無にかかわらず）「日本・その都道府県」とし、境界データの分類は `pref` が空の写真だけに使う。
  境界データが日本と判定した `pref` 空の写真は、日本の「地域不明」ではなく境界データの都道府県へ入れる。
- R7（必須）: 分類処理はオフラインで行い、既存のGPS・手動補正・写真・お気に入り・`pref/city` を変更しない。
- R8（必須）: 分類時座標と現座標が異なる結果は、再分類前でも集計・検索・表示に使わない。
  採用データや分類規則が変わった結果も同様に再分類対象とする。
- R9（必須）: 既存写真を再開可能な件数・時間上限つき処理で分類する。未処理・未解決・失敗を区別し、未解決行が毎回枠を占有しない。
- R10（必須）: 分類表がない旧DBの読み取り専用起動でもライブラリを開ける。読み取り要求から移行・分類・通信を始めない。
- R11（必須）: 出典・データ版・変換方法を記録する。単一バイナリ配布とmuslビルドを維持し、サイズ・メモリの増加を上限内に収める。
- R12（必須）: キーボード操作、狭い画面、応答の順序逆転に対する既存の保護を維持する。
- R13（あると良い）: 国の日本語名を miharashi の言い換え（「アメリカ」「韓国」など）と揃える。

## 受け入れ条件

- AC1（R1,R2）: 合成データの複数国・同名地域が別のIDで集計され、国・地域の選択で期待する写真だけが表示される。
  国・地域の表紙が同じ条件下の写真から選ばれる。
- AC2（R2,R6）: 日本の都道府県・市区町村の選択、読み仮名検索、同じ項目を押した選択解除が従来どおり使える。
  日本の各都道府県の件数から「市区町村未取得」（境界データで入った `pref` 空の写真）を引いた値と市区町村の件数が、
  変更前の `places` API と一致する（海岸・小島・県境・GPS が消えて `pref` だけ残った写真を含む合成データ）。
  今の画面が送る旧形式の絞り込み（`pref`・`pref&city`・`city`・`abroad`）が変更前と同じ結果を返す。
- AC3（R3）: 期間・bbox・除外の組み合わせで、国 = Σ地域 + 地域不明、Σ国 + 地域未判定 + 場所不明 = 全体 が成り立ち、各写真を一度だけ数える。
  地図の点は場所選択で消えず、カードによる移動でbbox絞り込みが追加されない。
- AC4（R4）: 日本語・英語・原表記の候補検索、国・地域を指定した写真検索、旅の地名表示に同じ分類が使われる。
  `pref` のある日本の写真も「日本」「Japan」「Tokyo」で当たる。国名と地域名の両方に一致する語で `q` 検索しても同じ写真が二重に返らない。
- AC5（R5）: 国のみ判定、競合、区域外、処理待ち、座標欠落、無効座標を含む合成データで、表示区分とその選択結果が一致する。
- AC6（R5）: 設計「判定手順」の 1〜4 の各分岐（境界上、穴、多重ポリゴン、海上、国境の共有辺、複数地域の共有辺）を
  合成ポリゴンで確かめる。国や地域を配列順・名前順で決めない。
- AC7（R7,R8）: 分類の計画後に座標変更・削除が起きた場合に古い結果を書かない。
  既存結果の座標・分類版が合わない場合、APIがそれを返さない。位置修正の直後に画面内の古い地域表示も消える。
  写真の削除後に残った分類行が集計に現れず、同期で片付けられる。
- AC8（R9）: 途中停止と再起動、適用失敗、分類版更新の後も再開し、処理済み未解決行を無限に再実行しない。
  1 サイクルの件数・時間の上限（設計の初期値）を超えない。dry-runはDB・永続キャッシュ・写真を書き換えず、分類自体の通信は0件。
  同期結果と運用タブに `regions` 段が表示され、段の一覧の試験が新しい個数で通る。
- AC9（R10）: 分類表なしの旧DB・取り込み無効でも旧国内表示と未分類表示が使え、APIから書き込みしない。
- AC10（R11）: 出典・ハッシュの検査が通り、通常ビルドがネットワークから境界データを取得せず、muslビルドと公開写真フィード契約の試験が通る。
  リリースバイナリの増加 15MB 以下、境界索引を作った後の常駐メモリ増加 80MB 以下、索引作成 2 秒以下（本番機相当で計測）。
  この数値は初期の目標値。段①の計測で超えるときは、データの簡略化か上限の見直しをユーザーに諮る。
  分類段が一度も動かない読み取り専用起動では境界ポリゴンを展開しない。
- AC11（R12）: DOM試験で国・地域の選択、候補の↑↓/Enter/Esc、古い応答の破棄、位置変更通知への追随を検証する。
  国全体が日付変更線にまたがる場合も世界全体への誤った急移動や無効bboxを発生させない。
- AC12（R7,R9）: 分類段のログに写真ID・座標・地名を出さない（件数と固定理由だけ）。

## 制約

- 写真や実際の撮影座標・個人の行動履歴をソース管理・試験fixtureへ入れない。fixtureは合成点と公開地点のみ。
- 大きいので 3 段（サブ Issue）に分け、段ごとに 1 本の PR にする（段の中身は設計「実装の順番」）。
  各段は単独でマージでき、単独で戻せること。本書と設計書は最初の段の PR に入れる。
- 既存のHTTP入力検証・CSRF・writer・取り込みロックを使い、分類専用の外部公開APIや認証方式を増やさない。

## 決まったこと

- 帰属に争いのある地域（北方領土・竹島など、`pref` が空の写真だけが対象）は、Natural Earth の日本視点版の国境
  （`ne_10m_admin_0_countries_jpn`）で国を判定する（2026-11-04 ユーザー決定）。Admin1 は既定版のまま。
- 採用する Natural Earth の版は 5.1.1（2026-11-04 時点の公式最新。T1 で確認）。

## 決まっていないこと

- 近隣推定（海岸線から少し外れた点の救済）を後で入れるか。初回の未判定件数を見て決める。
- 国によって細かすぎる Admin1（英国・フランス・イタリアなど）を Natural Earth の `region` 列でまとめるか。初回はまとめない。
